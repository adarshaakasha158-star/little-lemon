# Little Lemon Food Ordering App

Expo React Native app with onboarding, profile preferences, remote menu loading, and an offline SQLite menu cache.

## Run locally

```sh
cd little-lemon
npm install
npx expo start
```

Press `a` for Android or `i` for iOS, or use the Expo Go app to scan the QR code. Use Node.js 22.13+, 24.3+, or 26+ with SDK 57.
